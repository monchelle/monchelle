# 🎓 MSDA Learning Plan (WGU)

This directory contains my full **Master of Science in Data Analytics** learning plan, outlining the coursework, timeline, milestones, and portfolio development strategy I will follow from **November 2026 to April 2027**. The plan is designed to guide my progression through advanced analytics, machine learning, optimization, and data science methodologies while building a strong professional portfolio.

---

## 📘 Program Overview

The MSDA program at Western Governors University combines theoretical foundations with hands‑on, applied analytics work. Key focus areas include:

- Machine Learning  
- Advanced Analytics  
- Statistical Data Mining  
- Optimization  
- Data Storytelling  
- Deployment & Data Pipelines  
- Python, R, and SQL  
- Capstone project integrating business requirements and technical execution  

---

## 📅 Timeline (Nov 2026 → Apr 2027)

The learning plan follows a structured 6‑month schedule:

- **Foundations** — Analytics lifecycle, data management, programming  
- **Exploration & Modeling** — Data prep, statistics, supervised/unsupervised ML  
- **Advanced Techniques** — Deep learning, NLP, optimization  
- **Deployment** — Pipelines, functions, operationalization  
- **Capstone** — End‑to‑end analytics solution demonstrating technical and business impact  

A detailed calendar is included in the full plan.

---

## 🧩 Portfolio Milestones

Throughout the program, I will build a series of applied analytics projects, including:

- Data cleaning & wrangling project  
- SQL modeling & querying artifacts  
- Machine learning models (classification, regression, clustering)  
- NLP or neural network project  
- Optimization solution  
- Deployment pipeline  
- Full capstone project  

These milestones ensure continuous skill development and a strong portfolio by graduation.

## 🎯 Post‑Graduation Strategy

The learning plan includes a **90‑day transition roadmap** focused on:

- Updating professional branding  
- Publishing portfolio projects  
- Targeted job search  
- Technical interview preparation  
- Networking and community engagement  
- Securing a Data Analyst, Analytics Engineer, or Data Solutions Developer role
